# 🚗 Автосервисті басқару ақпараттық жүйесі (Auto Service Management System)

Жоба автосервис орталықтарының жұмысын автоматтандыруға, клиенттерді тіркеуге, жөндеу тапсырыстарын басқаруға және қосалқы бөлшектер есебін жүргізуге арналған.

---

## 📌 Жобаның мақсаты

Автосервис процестерін оңтайландыру, тапсырыстардың орындалу барысын бақылау және клиенттерге қызмет көрсету сапасын арттыру.

---

## 🚀 Негізгі мүмкіндіктері

- **👨‍💼 Клиенттерді басқару:** Клиенттер базасын, көлік мәліметтерін (VIN, мемлекеттік номер, модель) сақтау.
- **🛠 Жөндеу тапсырыстары (Orders):** Жаңа тапсырыс ашу, шеберді тағайындау, статусын бақылау (Күтілуде, Жөнделуде, Дайын).
- **📦 Қосалқы бөлшектер қолы (Inventory):** Қоймадағы бөлшектердің қалдығын көру және есепке алу.
- **💰 Қаржы және Чектер:** Көрсетілген қызметтер мен бөлшектердің жалпы құнын есептеу, чек басып шығару.
- **📊 Аналитика мен Есептер:** Күндік/айлық кірістерді және ең жиі жасалатын жөндеу түрлерін талдау.

---

## 💻 Технологиялық стек

- **Backend:** Python (Django / FastAPI) немесе Node.js / Java Spring Boot
- **Frontend:** HTML, CSS, JavaScript (React / Vue.js)
- **Database:** PostgreSQL / MySQL
- **Tools:** Git, GitHub, VS Code
